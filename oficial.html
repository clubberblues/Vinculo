❓ Como Jogar

Modo Solo

Preencha a ficha, role dados. Salva no seu navegador.

Modo Mesa
  1. Abra o menu Mesa no topo.
  2. Mestre: Crie a mesa e receba o código de 4 dígitos.
  3. Jogadores: Entrem com o código.
  4. Tudo é salvo na nuvem (Firebase). Não se perde ao limpar o navegador.
Fórmulas
  • Iniciativa = 10 + DES
  • PV = classe + 2×CON · PM = classe + INT
  • RM = classe + INT · CA = armadura + DES + bônus
  • ATKC/ATKL/ATKM = d20 + FOR/DES/INT
