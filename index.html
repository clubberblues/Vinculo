❓ Como Jogar

Conta e Mesas

Sua conta guarda a ficha. Crie uma mesa (Mestre) ou entre com um código.

Combate
  1. Mestre adiciona combatentes com nome, DES, PV, CA, RM.
  2. Mestre inicia o combate.
  3. No turno do jogador, ele toca no inimigo para atacar.
  4. Escolhe tipo de ataque ou magia.
  5. Sistema rola, compara com CA/RM, aplica dano.
Convite de Rolagem

Quando uma magia Tipo II é lançada, o alvo recebe uma notificação para rolar resistência na própria tela. O resultado volta para todos. Se o alvo for monstro, o Mestre rola em nome dele.

Fórmulas
  • Iniciativa = 10 + DES
  • PV = classe + 2×CON · PM = classe + INT
  • RM = classe + INT · CA = armadura + DES + bônus
  • CD de magia = 10 + INT + bônus do círculo
